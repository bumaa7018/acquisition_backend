# Нөхөх олговрын API (гадаад системд)

Төлөвлөгөөний **2.8.4** ажил: чөлөөлсөн газрын нөхөх олговрын мэдээг бусад
систем (ТЕГ, ШШГЕГ, үнийн мэдээний сан г.м.) машинаар уншиж авах гарц.

Гарц нь **дэлгэцийн тайлантай ИЖИЛ** тоог буцаана: зөвхөн нэгж талбарын
**үндсэн үнэлгээний урсгал** (`compensation.valuation_type` =
`parcel.selected_valuation_type`). Хөндлөнгийн болон МИКА-гийн зэрэгцээ
үнэлгээ, баримт бичиг, эзэмшигчийн холбоо барих мэдээлэл гадагш **гарахгүй**.

## Танилт

```
X-API-Key: <түлхүүр>
```
`Authorization: Bearer <түлхүүр>` хэлбэрийг ч хүлээн авна.

Түлхүүрүүд серверийн `.env`-д бүртгэгдэнэ (`нэр:түлхүүр`, таслалаар зааглана):

```
EXTERNAL_API_KEYS=teg:0f2c…,shshgeg:9ab1…
```

- Түлхүүр **тохируулаагүй бол гарц бүрэн хаалттай** (`503`) — санамсаргүй
  нээлттэй үлдэхгүй.
- Түлхүүр буруу/байхгүй → `401`.
- Түлхүүр тус бүрийн **нэр** серверийн логт бичигдэнэ (түлхүүр өөрөө хэзээ ч
  логлогдохгүй): `{"msg":"external compensation api","client":"teg","mode":"plan",…}`.
- Нэг IP-ээс минутад **120 хүсэлт** (хэтэрвэл `429`).
- Түлхүүр үүсгэх: `openssl rand -hex 32`

## GET /api/v1/external/compensations

**Гурван хэлбэрээр дуудна** — аль нэгийг ЗААВАЛ (эс бөгөөс `400`):

| # | Параметр | Юу буцаах |
|---|---|---|
| 1 | `parcel_id` | Тухайлсан **нэгж талбарын** нөхөх олговор + өртсөн талбайн мэдээлэл |
| 2 | `plan_parcel_id` | **Чөлөөлөлтийн төлөвлөгөөний нэгж талбарын дугаараар** — тэр талбараар үүссэн бүх чөлөөлөлтийн нэгж талбарууд + нийт дүн + **төлөвийн тоолол** |
| 3 | `plan_code` | **Төлөвлөгөөний дугаараар** (яг таарал) — тэр төлөвлөгөөнд хамаарах бүх чөлөөлөлтийн нэгж талбарууд + нийт дүн + **төлөвийн тоолол** |

Нэмэлт (заавал бус): `acquisition_id` (чөлөөлөлтийн UUID), `year` (төлөв
өөрчлөгдсөн он, олон удаа эсвэл таслалаар), `page`, `page_size` (анхдагч 50,
дээд тал 200).

`summary` нь **хуудаслалтаас хамаарахгүй** — шүүлтэд тохирох БҮХ мөрийн
нэгтгэл. Гурван хэлбэрт бүгдэд гарна (1-рт нэг талбарын өөрийн дүн).

### Жишээ дуудалтууд

```bash
KEY=<түлхүүр>
BASE=http://<host>:8080/api/v1/external/compensations

# 1. Нэгж талбарын дугаараар
curl -H "X-API-Key: $KEY" "$BASE?parcel_id=1600900137"

# 2. Чөлөөлөлтийн төлөвлөгөөний нэгж талбарын дугаараар
curl -H "X-API-Key: $KEY" "$BASE?plan_parcel_id=5029776&page_size=200"

# 3. Төлөвлөгөөний дугаараар
curl -H "X-API-Key: $KEY" "$BASE?plan_code=2026-04-011-9878&page=1&page_size=200"

# Нэмэлт: тодорхой чөлөөлөлт, эсвэл оноор шүүх
curl -H "X-API-Key: $KEY" "$BASE?acquisition_id=204314ea-…&year=2026"
```

## Талбаруудын тайлбар

| Талбар | Тайлбар |
|---|---|
| `mode` | Ямар хэлбэрээр дуудсан: `parcel` / `plan_parcel` / `plan` / `acquisition` |
| `summary.acquisition_count` | Шүүлтэд орсон чөлөөлөлтийн тоо |
| `summary.parcel_count` | Нэгж талбарын тоо |
| `summary.acquisition_area_m2` | Чөлөөлөгдсөн (өртсөн) талбайн нийлбэр (м²) |
| `summary.parcel_area_m2` | Нэгж талбаруудын бүтэн талбайн нийлбэр (м²) |
| `summary.status_counts` | Чөлөөлөлтийн үндсэн нэгж талбаруудын **төлөвийн тоолол** |
| `parcels[].area_m2` | Нэгж талбарын бүтэн талбай (м²) |
| `parcels[].acquisition_area_m2` | Чөлөөлөгдсөн (өртсөн) талбай (м²) |
| `parcels[].remaining_area_m2` | Үлдэх талбай (м²) |
| `right_type` / `right_type_name` | 1 Ашиглах, 2 Эзэмших, 3 Өмчлөх |
| `status` / `status_name` | Нэгж талбарын төлөв |
| `status_date` | Төлөв сүүлд өөрчлөгдсөн огноо |
| `compensation.land` | Газрын нөхөх олговор (₮) |
| `compensation.real_estate` | Үл хөдлөх хөрөнгийн нөхөх олговор (₮) |
| `compensation.property` | Бусад эд хөрөнгийн нөхөх олговор (₮) |
| `compensation.other` | 3 ангилалд ороогүй үлдэгдэл — задаргаа нийттэй тэнцэх баталгаа |
| `compensation.total` | Нийт дүн (₮) |

Дүн нь **үндсэн үнэлгээний урсгалын** нөхөх олговрын нийлбэр. Олговор
бүртгэгдээгүй нэгж талбарын дүн `0` байна (мөр нь хэвээр гарна).

## Алдааны хариу

| Код | Тохиолдол |
|---|---|
| `400` | Шүүлтүүр заагаагүй, эсвэл `acquisition_id` нь UUID биш |
| `401` | Түлхүүр байхгүй/буруу |
| `429` | Хүсэлтийн хязгаар хэтэрсэн |
| `503` | Сервер дээр `EXTERNAL_API_KEYS` тохируулаагүй |

Бүх алдаа `{"code":…,"error":"…","message":"…"}` хэлбэртэй, мессеж нь монголоор
(`Accept-Language: en` үед англиар).
